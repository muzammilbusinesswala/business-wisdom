ایک دفعہ کی بات ہے، ایک بندہ کسی کے گھر گیا۔ رات ہو چکی تھی، بھوک لگی ہوئی تھی۔ گھر والے نے روٹی نمک کے ساتھ کھلا دی۔ سادہ سا کھانا، مگر پیٹ بھر گیا۔
سال گزر گئے۔ وہی بندہ اب کامیاب ہو چکا تھا۔ ایک دن بازار میں اُس گھر والے سے ملاقات ہوئی، جس نے کبھی اُسے روٹی کھلائی تھی۔ سب کے سامنے وہ آدمی بولا:
"یاد ہے؟ میں نے ہی تمہیں اُس رات کھانا کھلایا تھا۔"
بندہ خاموش رہا۔ مسکرایا۔ اور اندر ہی اندر ایک بات سیکھ گیا —
جو احسان زبان پر آ جائے، وہ احسان نہیں رہتا۔
جو مدد یاد دلائی جائے، وہ مدد نہیں، بوجھ بن جاتی ہے۔
ترکی میں ایک خوبصورت کہاوت ہے:
"اگر روٹی نمک کے ساتھ بھی کھانی پڑ جائے تو کھا لینا، مگر اُس شخص سے بچنا جو بعد میں لوگوں کو بتاتا پھرے کہ روٹی میں نے کھلائی تھی۔"
یہی بات کاروبار پر بھی لاگو ہوتی ہے۔ جو لوگ آپ کی مدد کرکے احسان جتاتے ہیں، وہ آپ کے سب سے بڑے دشمن ثابت ہوتے ہیں — کیونکہ وہ مدد نہیں کرتے، آپ کو نیچا دکھانے کا موقع تلاش کرتے ہیں۔
اصل کامیابی وہی ہے جو خاموشی سے دی جائے، اور خاموشی سے قبول کی جائے۔
